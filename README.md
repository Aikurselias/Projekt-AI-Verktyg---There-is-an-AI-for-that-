# AI Projekt – Turbo AI

Detta är en färdig statisk webbsida för en skolredovisning om AI-verktyget Turbo AI.

## Filer

- `index.html` – själva webbsidan.
- `assets/images/` – skärmklipp från testerna.
- `.nojekyll` – gör att GitHub Pages publicerar filerna som en vanlig statisk webbsida.

## Så publicerar du på GitHub Pages

1. Skapa ett nytt repository på GitHub, till exempel `ai-projekt-turbo-ai`.
2. Ladda upp alla filer och mappar i detta paket.
3. Gå till **Settings** → **Pages**.
4. Välj **Deploy from a branch**.
5. Välj branch **main** och folder **/root**.
6. Klicka på **Save**.
7. Vänta någon minut. GitHub visar sedan länken till sidan.
